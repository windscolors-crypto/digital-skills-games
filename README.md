# ألعاب المهارات الرقمية

موقع ألعاب صفّية للمهارات الرقمية، الصفوف ٧–١٠، الفصل الأول.

## إضافة لعبة جديدة

ارفعا ملف اللعبة باسم يتبع هذه القاعدة، فتتفعّل خانته في الصفحة الرئيسية تلقائيًا:

```
g{الصف}/u{الوحدة}-l{الدرس الأول}-{الدرس الثاني}.html
```

| مثال | المعنى |
|---|---|
| `g8/u1-l3-4.html` | الصف الثامن · الوحدة ١ · الدرسان ٣ و٤ |
| `g9/u1-l5.html` | الصف التاسع · الوحدة ١ · الدرس ٥ (منفرد) |
| `g10/u2-l7.html` | الصف العاشر · الوحدة ٢ · الدرس ٧ (منفرد) |

الدروس تُجمع أزواجًا: ١-٢، ٣-٤، ٥-٦، والدرس الأخير يبقى منفردًا إذا كان العدد فرديًا.

الألعاب الإضافية غير المبنية على الكتاب توضع في `extra/` وتُضاف يدويًا إلى قائمة `EXTRAS` في `index.html`.

بعد الرفع قد يحتاج الموقع حتى ١٠ دقائق ليظهر التحديث.
